GEPA × VLA-JEPA — End-to-End Run Book

Reflective test-time instruction optimization over a frozen vision-language-action policy on LIBERO-Plus. Zero weight changes — only the conditioning text evolves. Every (strategy, task) cell is written to the append-only ledger.

Pipeline: bench/libero/gepa_daft.py  ·  Algorithm: archetype.optimize.gepa  ·  Workers: archetype-libero-plus-env, archetype-vla-jepa

1 · The thesis in one paragraph

A frozen VLA policy (VLA-JEPA) underperforms on the LIBERO-Plus Language dimension — same scene, perturbed instruction (~85% vs. ceiling on clean text). The claim: a lot of that gap is conditioning quality, not capability. So we run GEPA (Agrawal et al. 2025) to evolve an instruction-rewrite strategy at test time — reflecting on simulator outcomes, never touching a single weight. The simulator's pass is ground truth (no LLM judge). The honest baseline is the perturbed instruction verbatim.

Why this is a clean result either way. Tier-1 is a fixed-arm ablation whose ordering is the legitimacy test: A ≤ D < B-seed < C. If a neutral paraphrase (D) already recovers the gap, the effect is an artifact. If only grounding (B/GEPA) recovers it, the gap was conditioning. Tier-2 (GEPA) then shows how far reflective search pushes it under a fixed rollout budget.

2 · System architecture

The whole optimization is one Modal function (run) whose body is Daft DataFrame ops. The only .remote() calls leave the box to the two deployed workers — the same proven path as the baseline sweep. Daft gives intra-container parallelism over rollouts.

archetype-vla-jepa

The VLA-JEPA policy, weights frozen. Conditioned only on the (possibly rewritten) instruction + frames. Never fine-tuned in this experiment.

4 · One evaluation cell (the inner loop)

A "metric call" = one (strategy, task) cell = n_seeds rollouts. This is the unit the GEPA budget is counted in.

# evaluate(): rewrite is split on the null predicate so prompt() NEVER runs on the
# identity arm (daft when().otherwise() evaluates BOTH branches for every row).
named = cells.where(~col("strategy_text").is_null()).with_column(
    "grounded",
    prompt(messages=dfmt("{}\n\nOriginal instruction:\n{}\n\n"
                         "Rewritten instruction (one imperative sentence):",
                         col("strategy_text"), col("perturbed_instr")),
           model=REWRITE_MODEL, use_chat_completions=True, max_tokens=200),
)
identity = cells.where(col("strategy_text").is_null()).with_column(
    "grounded", col("perturbed_instr"))
cells = named.concat(identity)
cells = cells.with_column("res", evaluator.eval(col("suite"), col("task_id"), col("grounded")))
# RolloutEvaluator.eval — failure-isolated: one bad cell can't abort the whole search
try:
    async with ArchetypeRuntime() as rt:
        per_trial = await run_episode_batched(env_client=env, policy_client=pol,
            suite=suite, task_id=task_id, seeds=seeds, env_keys=env_keys,
            max_steps=self.max_steps, storage=store, runtime=rt,
            use_frames=True, instruction=instruction)
except Exception as exc:
    return {"success_rate": 0.0, "successes": 0, "n": 0, "feedback": f"harness error: {exc}"}
return _summarize(per_trial, self.max_steps)

_summarize turns per-seed outcomes into the reflective feedback GEPA reads — distinguishing timeouts ("target likely never grasped — instruction ambiguous") from wrong-outcome failures ("finished but failed the goal — instruction underspecifies the target").

5 · The GEPA loop, step by step

flowchart TD SEED["seed strategy → full-eval on ALL tasks"] --> POOL[("candidate pool
per-instance score vectors")] POOL --> SEL["Pareto-select a parent (Alg 2)
sample ∝ #instances won"] SEL --> MB["sample a minibatch of tasks"] MB --> REF["reflect on feedback → child strategy
(Claude opus-4-8)"] REF --> CE["eval child on the minibatch → σ'"] CE --> GATE{"σ' > σ ?"} GATE -->|no| SEL GATE -->|yes| FULL["full-eval child on ALL tasks"] FULL --> POOL POOL -->|budget exhausted| BEST["return best candidate by mean score"]
1
Seed. Full-eval SEED_STRATEGY on every task → the first pool entry, with a per-instance score vector (Pareto needs the vector, not the mean).
2
Pareto-select a parent (Algorithm 2). Per instance, find the best score; a candidate "wins" an instance if it ties that best. Prune strictly-dominated candidates; sample the survivors proportional to #instances won. A specialist that wins one hard task survives even if its mean is low — the diversity beam search throws away.
3
Minibatch + reflect. Sample a minibatch of tasks; build a feedback block from the parent's cached per-instance outcomes; Claude proposes an improved strategy (answer-blind).
4
Accept gate. Eval the child on the minibatch (σ′). Accept iff σ′ > σ (the parent's score on that same minibatch). Only then pay for a full-eval and add it to the pool.
5
Budget. Loop while metric calls remain (1 call = 1 strategy × 1 task = n_seeds rollouts). Return the pool's best by mean score.
# archetype/optimize/gepa.py — the loop (effects injected by gepa_daft)
pool = [_candidate("gepa-seed", seed_text, eval_fn("gepa-seed", seed_text, instance_ids), instance_ids)]
spent = len(instance_ids)
while spent + minibatch <= budget:                          # Alg 1 L8: budget
    parent = pareto_select(pool, instance_ids, rng)          # Alg 2
    mb = rng.sample(instance_ids, min(minibatch, len(instance_ids)))
    sigma = sum(parent["scores"][i] for i in mb) / len(mb)
    child_text = reflect_fn(parent["text"], fb)               # UpdatePrompt
    c_res = eval_fn(f"{csid}-mb", child_text, mb)
    sigma_prime = sum(c_res[i]["s"] for i in mb) / len(mb)
    if sigma_prime > sigma and spent + len(instance_ids) <= budget:  # accept gate
        full = eval_fn(csid, child_text, instance_ids)        # full-eval on D_pareto
        pool.append(_candidate(csid, child_text, full, instance_ids))

6 · The ledger (queryable, reproducible)

Every cell is appended as Lance under /results/gepa_daft (the libero-eval-results Modal Volume). Tier-1 arms → /arms; every GEPA cell → /gepa. Each row: strategy_id, task_id, grounded, success, feedback. The whole search is replayable from the ledger.

import daft
arms = daft.read_lance("/results/gepa_daft/arms")
arms.groupby("strategy_id").agg(daft.col("success").mean()).sort("strategy_id").show()

7 · How to run it

Prereqs — deploy the two workers (once / after edits)

modal deploy bench/libero/libero_plus_worker.py   # archetype-libero-plus-env
modal deploy bench/libero/modal_worker.py         # archetype-libero-env (standard suites)
# archetype-vla-jepa (frozen policy) is already deployed and serving.
Always submit via spawn(), never modal run. modal run --detach keeps your local CLI as the job driver — if the session is reaped, Modal cancels the run mid-flight. modal deploy + spawn() runs the job server-side, fully decoupled (submit returns in ~1s; close your laptop). bench/libero/submit_gepa.py wraps this.

Deploy once (and after any gepa_daft.py edit)

modal deploy bench/libero/gepa_daft.py   # registers run() as a persistent cloud function

Smoke (cheap — proves the whole pipeline)

python bench/libero/submit_gepa.py \
  --suite libero_goal --n-tasks 2 --n-seeds 2 --max-steps 40 \
  --budget 14 --minibatch 1
# → prints a call id; fetch with: submit_gepa.py --fetch <id>  (or `make status`)

Headroom scan (which suite is worth optimizing)

# baseline (perturbed-instruction) success per Language ordinal, per suite
modal run --detach bench/libero/libero_plus_sweep.py \
  --suite libero_goal --n-tasks 10 --trials 3 --max-steps 300
# repeat for libero_object, libero_10. Spatial is already confirmed at ceiling.
# Pick the suite with the LOWEST baseline → most room for a real Δ.

The overnight run (#19 — the big one)

python bench/libero/submit_gepa.py \

Flags map 1:1 to main(). --n-tasks→n_tasks, --max-steps→max_steps, --budget→GEPA rollout budget (metric calls), --minibatch→the mutate/accept minibatch size. --no-do-gepa runs Tier-1 arms only.

8 · Cost & scale (overnight config)

PhaseRolloutsLLM calls
Tier-1 arms (4 × 8 tasks × 5 seeds)160 episodes~24 rewrites (3 non-identity arms × 8)
Tier-2 GEPA (budget 60 cells × 5 seeds)~300 episodes~60 rewrites + ~1 reflect / generation
Total~460 episodes × 300 steps~90 Claude calls

Wall-clock is dominated by GPU rollouts; Daft runs up to min(n_tasks, 8) concurrently (per-process RBAC isolation via use_process=True). LLM calls are cheap relative to rollouts. Timeout on run() is 6 h. Episodes are bounded by max_steps; a cell that never grasps just times out and is recorded as a failure (not a crash).

9 · What to watch

  • Ordering, not absolute numbers. A ≤ D < B-seed validates the conditioning hypothesis; D ≈ B would mean "any rewrite helps" (weaker claim).
  • GEPA > B-seed. The reflective search should beat the un-evolved seed, and approach C-oracle without ever naming the answer (answer-blind is enforced in the reflect prompt).
  • Pool diversity. The trace records each generation's parent, σ, σ′, accept/reject. Healthy runs accept early then plateau (rejects) as the frontier saturates.
  • No silent zeros. A cell with feedback="harness error: …" is an isolated failure, not a real 0% — grep the ledger for it before trusting an arm's mean.
