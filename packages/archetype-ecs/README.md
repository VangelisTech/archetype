# archetype-ecs

The generic DataFrame-first ECS framework and process host for Archetype world
libraries.

```bash
uv add archetype-ecs
```

The base distribution starts without a domain library. Install
`archetype-missions`, `archetype-physical-ai`, or `archetype-research` when an
application needs those capabilities. Project documentation lives at
<https://archetype.vangelis.tech/docs>.
